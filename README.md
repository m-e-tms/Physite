# Physite
Das ist Seite des Physikprofils
## Beschreibung
Das jetztige Physikprofil soll eine schulinterne Infomrationsseite für Schüler in jüngeren Jahrgängen programmieren. Die jetztige Dateinstruktur stellt den aktuellen Fortschritt da. Diese Seite wird von 12 Menschen erstellt, die sich für dieses Projekt in Gruppen unterteilt haben. Diese Seite ist nicht wirlklich für den eingen Nutzen gedacht. Mehr eher für Schüler...
